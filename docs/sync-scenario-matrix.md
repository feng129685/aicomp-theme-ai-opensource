# 同步场景矩阵

以下场景用于实现和测试同步状态语义。仓库中的 JSON 是合成夹具，不代表真实接口已经部署。

| 编号 | 场景 | 预期状态 | 必须保留 | 失败判定 |
| --- | --- | --- | --- | --- |
| SYNC-001-ONLINE | 设备 A 在线上传，设备 B 首次拉取 | 已同步 | 编号、课程、资料、解析证据和任务关系一致 | 任一稳定编号或原文引用变化 |
| SYNC-002-OFFLINE | 设备 A 断网修改任务 | 离线待同步 | 本机修改和原有副本，恢复联网后可重试 | 断网时显示已同步或修改丢失 |
| SYNC-003-FAILURE | 服务端返回 HTTP 503 | 同步失败 | 本机副本、错误原因和重试入口 | 丢失副本或错误显示成功 |
| SYNC-004-CONFLICT | 两台设备修改同一课程地点 | 冲突待选择 | 信息楼301、实验楼205 两个候选值 | 静默覆盖任一版本 |

实现真实同步时，还应记录设备、版本、对象编号、时间和同步状态；但本仓库不提供服务器实现，也不以夹具测试替代端到端验收。
