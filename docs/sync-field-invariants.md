# 同步字段与证据不变量

这组公开夹具用于验证课程、资料、解析结果和任务在多设备同步设计中的关系保持规则。它只描述数据语义和测试边界，不实现账号、服务器或网络传输。

## 稳定关系

课程、资料和任务分别使用自己的稳定编号。同步端应按 `course_id`、`document_id`、`asset_id` 和 `task_id` 建立关系，不能按名称、数组位置或文件名临时匹配。

同步前后应保持以下内容一致：

1. 四类稳定编号及其关联关系。
2. 课程名称、教师、地点、星期、开始时间、结束时间和教学周次。
3. 解析状态，不能把失败伪装成成功，也不能把成功降级为待解析。
4. 解析字段的 `evidence_field_ids` 和 `source_quotes`。
5. 已确认任务的标题、截止时间、完成状态和提醒时间。

原文引用是解析结果的可追溯依据。编号或引用发生变化时，即使课程名称仍然正确，也应判定为关系校验失败。

## 状态边界

`已同步`、`离线待同步`、`同步失败` 和 `冲突待选择` 只属于同步测试层，不扩展 `ParseResult v1` 或 `ChangeProposal v1` 的枚举。

- 离线修改只能进入本地待同步状态，不能提前显示为已同步。
- 服务失败时保留本机副本，记录错误并提供重试。
- 冲突时保留两边的候选值，等待用户选择后再形成最终值。

成绩情景输入和计算结果不在同步基线中，参见 `not_synced` 字段。
